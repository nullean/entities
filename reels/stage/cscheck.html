the engine underneath

Built on CsCheck.

CsCheck is an excellent property-based testing library for .NET: fast, and it finds the smallest case that still fails. Entities builds on it, and adds what a test can't know without your rules.

first-class properties

Your rules are the properties.

Each one is a named value with a shape. The shape tells the tests what to ask, so nobody writes the property by hand.
